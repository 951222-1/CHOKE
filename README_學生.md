# 防哽咽偵測 桌面版（學生版）

用電腦的鏡頭跟麥克風,即時看有沒有人吃東西噎到。這個資料夾是給你自己在電腦上跑起來、
順便看程式怎麼寫的。先打開 `專案說明.html` 看整個系統長什麼樣、為什麼這樣做,再照下面四步跑。

## 怎麼跑（照順序點就好）

1. **雙擊 `1_建立虛擬環境.bat`** — 幫這個 app 開一個獨立的 Python。只要做一次。
2. **雙擊 `2_安裝套件.bat`** — 裝需要的套件。聲音那包(tensorflow)很大,慢慢等它跑完。
3. **雙擊 `3_啟動系統.bat`** — 開鏡頭。第一次會下載臉部/聲音模型,等幾秒。
4. **開始用** — 對著鏡頭,臉上會出現綠點;對麥克風咳一聲,`Audio Choke` 那條會動;
   把手靠近喉嚨約一秒,會跳出「手勢窒息」警報。看完按 **`q`** 關掉。

> 沒裝到聲音那包也沒關係,程式會自動變成「只看影像」模式,一樣能跑。

## 檔案大概是什麼

- `防哽咽裝置4_2.py` — 主程式。最底下的 `main()` 是整個流程,想看怎麼跑從那裡看。
- `gesture.py` — 手有沒有抓喉嚨(國際窒息手勢)。
- `silent_choke.py` — 無聲窒息(嘴開、不動、又沒聲音)。
- `cyanosis.py` — 嘴唇有沒有發紫(缺氧)。
- `evidence_fusion.py` — 把上面這些線索合在一起判斷,減少誤報。
- 這四個小檔最短也最好懂,想學演算法先看它們。

## 一個小提醒（為什麼 .bat 全是英文）

這些 .bat 故意全部寫英文,不放中文、不放 emoji。因為 Windows 中文系統的終端機
預設編碼是 cp950,.bat 裡如果混中文/emoji 很容易變亂碼,甚至讓程式一閃就關。
所以檔名用中文（給你看順序）,內容用英文（保證跑得動）。細節在 `專案說明.html` 有講。
