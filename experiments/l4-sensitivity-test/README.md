# L4 高敏感度測試副本（TEST ONLY）

本資料夾是獨立的探索性測試設定；**不是正式版、不是臨床驗證，也不可用於實際照護或作為唯一安全監控。** 它不會覆蓋 repo 根目錄的正式程式。

## 本副本的試驗變更

- L4 累積門檻：3.0 → 2.5 秒
- 動作中斷寬限：0.6 → 0.9 秒；累積衰減率：0.5 → 0.25
- 咳嗽後手勢觀察窗：8 → 12 秒
- 身體動作：最短觀察窗 0.45 → 0.35 秒、位移跨度 0.12 → 0.10、累計速度 1.2 → 1.0
- 喉嚨／胸口感應圈略擴大；手部有效關節點降為 1
- 影像咳嗽門檻：標準差 18 → 15、速度 10 → 8、確認幀數 6 → 4
- 音訊咳嗽門檻：0.15/0.20/0.32 → 0.12/0.18/0.28

降低門檻可能增加誤報；這些數值只為安全的受控示範測試，沒有臨床依據。L4 仍只會依既有三條路徑判定，不代表任何哽噎情形都一定會觸發。

## 執行

1. 在此資料夾依序執行 `1_建立虛擬環境.bat`、`2_安裝套件.bat`。
2. 雙擊 `啟動L4高敏感度測試.bat`。
3. 啟動器會清空 `LINE_TOKEN`，避免傳送真實 LINE 通知；本機警報視窗／蜂鳴仍可能出現。
4. 結束後若有錯誤，查看 `sensitivity-test.log`。

啟動器優先使用此 repo 根目錄的 `face_landmarker.task` 和 `hand_landmarker.task`；若沒有，才使用本資料夾內的模型檔。首次音訊啟動可能需要網路下載 YAMNet 模型。

## 單元測試

在此資料夾執行：

```powershell
python -B -m unittest discover -s . -p "test_l4_safety.py" -v
python -B -m unittest discover -s tests -p "test_l4_sensitivity_profile.py" -v
```

測試只驗證程式邏輯／合成動作，**不等於攝影機實測或臨床驗證**。不要用真實哽噎事件或需要照護的對象進行測試。
