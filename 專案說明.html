防哽咽即時監測系統

用鏡頭看臉、用麥克風聽聲音,判斷有沒有人在吃東西時噎到。發現可疑就警報。 這頁把整個系統怎麼運作、為什麼這樣設計講一遍。

  • 3 個裝置協作
  • 6 種偵測線索
  • 68 項自動測試通過
  • 桌面版 已實跑驗證

這是什麼

吃東西噎到、氣管被塞住,幾分鐘內就可能造成缺氧腦傷。照護長輩或小孩時,不可能一直 盯著看。這個系統就是想當那雙「不會累的眼睛跟耳朵」,一發現不對就馬上叫人。

它不是靠單一招判斷,而是同時看好幾種線索一起下決定 —— 因為任何一種訊號單獨看都會 誤判,合起來看才準。這頁下面會一個一個講。

你手上這個資料夾是「桌面版」:在一台 Windows 電腦上,用它自己的鏡頭跟麥克風就能跑。

它怎麼判斷有人噎到

六種線索,分別寫在幾個小檔裡,想看演算法從這些檔看最快。

咀嚼狀態機

追蹤嘴巴開合跟下巴動作,判斷現在是「張嘴吃 → 咀嚼 → 吞嚥 → 觀察」哪個階段。 咀嚼太久沒吞下去,就是可疑訊號。

聲音嗆咳 YAMNet

用 Google 訓練好的聲音辨識模型,聽麥克風有沒有咳嗽、喘、清喉嚨這類聲音。

手抓喉嚨 gesture.py

人噎到會反射性抓自己的喉嚨,這是全世界通用的窒息手勢,可靠度很高。

無聲窒息 silent_choke.py

最危險的一種:氣管完全塞住時,人是發不出聲、也咳不出來的。所以反過來抓 「嘴開著、身體不動、又幾乎沒聲音」持續好幾秒。靠聽聲音的方法反而會漏掉這種。

嘴唇發紫 cyanosis.py

缺氧到後期嘴唇會轉青紫。看嘴唇顏色裡藍色佔多少,太高就是真的缺氧的客觀證據。

多線索融合 evidence_fusion.py

把上面的線索收在最近幾秒的「時間窗」裡各給分數加起來,超過門檻才報。這樣不會 因為單一訊號抖一下就亂叫,大幅減少誤報。

三個裝置怎麼分工

桌面版可以單獨用;嵌入式版是「前哨 + 大腦」兩台一起。

Windows 桌面版
一台電腦全包:影像 + 聲音 + 上面全部的判斷。你這個資料夾就是它。
— — — 或是穿戴/床邊的兩台版本 — — —
ESP32-S3 前哨
小晶片,一直聽麥克風,本地先粗判、先嗶嗶叫(斷網也能自己叫)。
↓ WiFi 把聲音串給大腦 · 大腦回傳確認 ↓
Raspberry Pi 大腦
算力較強,跑完整的聲音模型再確認一次,發 LINE、寫紀錄。

好處是「快」跟「準」兼得:前哨反應快,大腦判斷準;而且大腦掛掉時,前哨照樣能自己 警報,不會整個系統一起死。

為什麼所有 .bat 都避開 cp950

這是這個專案踩過、也修掉的一個真實坑,值得講給你聽,因為很多人會遇到。

Windows 繁體中文版的「命令列/終端機」預設用一種叫 cp950(Big5)的 編碼。但我們寫程式習慣用 UTF-8。這兩種對不上時就會出事 —— 尤其是 .bat 檔裡如果放了中文字或 emoji:

會發生什麼:雙擊 .bat,視窗跳出一堆亂碼,更慘的是有時候 「一閃就關」,根本來不及看它在講什麼 —— 因為 cp950 解不了那些 UTF-8 的位元組, 直接讓批次檔解析出錯。

怎麼修:把 .bat 的內容全部寫成純英文(純 ASCII), 一個中文、一個 emoji 都不放。ASCII 在任何編碼下都長一樣,所以到哪台電腦都穩。

不穩(中文/emoji 在 cp950 會亂碼、甚至閃退):
  echo 正在安裝套件...

穩(純英文,到哪都一樣):
  echo Installing packages...

所以你會看到:檔名是中文(讓你一眼看懂順序:1、2、3),但打開後裡面是英文。 檔名由 Windows 用 Unicode 存,雙擊沒問題;內容純英文,保證跑得動。這不是偷懶,是刻意 為了「換一台電腦也不會壞」。

同樣的道理:主程式裡如果 print 中文/emoji,當輸出被導到檔案或被程式擷取時 (不是直接顯示在終端機),也會因為 cp950 而報錯。所以測試時我們會先設 PYTHONIOENCODING=utf-8 把輸出強制成 UTF-8。

怎麼在你電腦上跑

照順序雙擊三個 .bat 就好,第 4 步是實際操作。

  1. 1_建立虛擬環境.bat — 幫這個 app 開一個獨立的 Python。只要做一次。
  2. 2_安裝套件.bat — 裝需要的套件。聲音那包(tensorflow)很大,慢慢等它跑完。
  3. 3_啟動系統.bat — 開鏡頭。第一次會下載臉部/聲音模型,等幾秒。
  4. 開始用 — 臉上會出現綠點;對麥克風咳一聲,Audio Choke 那條會動;把手靠近 喉嚨約一秒會跳窒息警報。看完按 q 關掉。

沒裝到聲音那包也沒關係,程式會自動變成「只看影像」模式,一樣能跑。

這是教學/照護輔助用途的專案,不是醫療器材,不能當成唯一的安全依靠。 真正照顧人的時候,還是要有人在。
